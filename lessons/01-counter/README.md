# Урок 1: счётчик
Бит: провод с 0 или 1. clk: провод, который качается 0-1-0-1. Регистр запоминает значение на подъёме clk. Счётчик: регистр, который на каждом такте кладёт в себя q + 1.
Запуск: iverilog -o sim counter.v tb.v && vvp sim && gtkwave w.vcd
Вопрос на понимание: сколько значений принимает 8-битный q и что происходит после максимального?
